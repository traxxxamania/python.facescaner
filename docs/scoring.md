# Модель оценки TIER CHECK

Версия модели: **`tier-check-score-1.0.0`**  
Версия рубрики: **`2026.10`**  
Артефакты: [`app/models/score_model.npz`](../app/models/score_model.npz),
[`app/models/score_model.json`](../app/models/score_model.json)  
Скрипт обучения: [`training/train_score_model.py`](../training/train_score_model.py)

> Это мем-приложение. Модель не оценивает реальную привлекательность человека,
> не обучалась на фотографиях или человеческих оценках и не является медицинским
> инструментом.

## Зачем модель

Раньше итоговый балл складывался из эвристик и стабильного хеш-джиттера. Из-за
джиттера один и тот же кадр мог получить немного разные баллы, а формула выглядела
как случайность. Теперь:

1. Шесть метрик считаются по изображению (см. ниже).
2. Метрики округляются до целых — ровно те числа, которые видит пользователь.
3. Обученная NumPy-модель превращает эти шесть чисел в балл `1…100`.
4. Балл детерминирован: одинаковые шесть чисел всегда дают одинаковый результат.
   Хешей, seed и случайного джиттера в оценке больше нет.

## Шесть метрик

| Ключ | Подпись | Вес | Что измеряет изображение |
| --- | --- | ---: | --- |
| `jaw` | ЧЕЛЮСТЬ | 24% | контраст линии подбородка и нижней трети |
| `symmetry` | СИММЕТРИЯ | 18% | смещение носа и рта относительно глаз |
| `harmony` | ПРОПОРЦИИ | 22% | соотношение сторон лица, положение глаз и рта |
| `skin` | КОЖА | 16% | текстура и равномерность света на щеках |
| `hair` | ОБЪЁМ | 10% | края и текстура волос над лицом |
| `light` | СВЕТ | 10% | яркость, контраст, пересветы и провалы |

Все метрики нормированы в `0…100`. Они описывают **кадр**, а не человека:
свет, ракурс, камера и причёска влияют на них сильнее любых реальных черт.

## Публичная рубрика

Рубрика — это «правила игры», по которым сгенерированы метки для обучения.
Она специально простая и объяснимая.

```text
base        = 0.24*jaw + 0.18*symmetry + 0.22*harmony
            + 0.16*skin + 0.10*hair + 0.10*light
weakest     = min(jaw, symmetry, harmony, skin, hair, light)
consistency = 2.5 * smoothstep(weakest, 25, 85)
light_gate  = 0.82 + 0.18 * smoothstep(light, 12, 60)
penalty     = max(0, 30 - weakest) * 0.18
score       = 7 + 0.90 * (base + consistency) * light_gate - penalty
score       = clip(score, 1, 99)
```

`Smoothstep(x, a, b)` — плавная S-образная функция от 0 до 1. Она даёт бонус за
ровные метрики и мягко ограничивает вклад тёмного кадра.

### Тировые предохранители

Средний балл не должен прятать один проваленный параметр:

- если самая слабая метрика **меньше 45**, балл ограничивается **81.9** —
  в `CHAD` нельзя попасть с провалом;
- если самая слабая метрика **меньше 65**, балл ограничивается **92.9** —
  в `TRUE ADAM` нужны все шесть метрик на уровне.

Предохранители применяются и к рубрике, и к выходу модели.

## Нейросеть

Модель — маленький полносвязный MLP:

```text
6 → 32 (ReLU) → 24 (ReLU) → 1
```

- Вход: шесть метрик, делённых на 100.
- Выход: балл в долях единицы, умножается на 100 и обрезается до `1…99`.
- Инференс: только NumPy, без PyTorch/TensorFlow и без внешних API.
- Параметры: `w1, b1, w2, b2, w3, b3, feature_scale` в `score_model.npz`.
- Метаданные и модельная карта: `score_model.json`.

Модель учится **воспроизводить рубрику**, а не угадывать человеческую красоту.
Это компактная и стабильная аппроксимация формулы, которую можно объяснить.

## Обучение

| Параметр | Значение |
| --- | --- |
| Обучающие данные | 80 000 синтетических векторов из шести метрик |
| Метки | баллы публичной рубрики |
| Разбиение | 60 000 / 10 000 / 10 000 (train / val / test) |
| Эпохи | 180 |
| Батч | 512 |
| Оптимизатор | Adam, learning rate `2e-3` |
| Seed | `20261028` |
| Функция потерь | MSE по нормированному баллу |

Данные не содержат фотографий, имён, лиц или человеческих оценок
привлекательности. Используются только синтетические числа, равномерное
покрытие диапазона и краевые случаи (слабые/сильные наборы и «одна проваленная
метрика»).

Воспроизвести артефакты:

```bash
python -m training.train_score_model
```

Скрипт перезаписывает `app/models/score_model.npz`, `app/models/score_model.json`
и `training/report.json`.

## Метрики качества

Результаты на отложенной тестовой выборке (10 000 векторов):

| Метрика | Значение |
| --- | ---: |
| Test MAE | **0.215 балла** |
| Максимальная абсолютная ошибка | **2.80 балла** |
| R² | **0.9995** |
| Локальные нарушения монотонности | 15 из 10 000 проверок |
| Максимальное падение при улучшении метрики | **0.50 балла** |

Модель практически монотонна: в 99.85% случайных проверок увеличение одной
метрики не уменьшает балл. Остаточные отклонения — цена аппроксимации
непрерывной формулы нейросетью; они детерминированы и ограничены половиной
балла. Тест в `tests/test_scoring.py` требует, чтобы локальное падение было
меньше одного балла.

## Ограничения

- Рубрика придумана для мема; у неё нет научного обоснования.
- Метрики измеряют картинку, а не человека: свет и ракурс меняют балл.
- Модель не проверялась на реальных людях и не подходит для решений о человеке.
- Балл — не вероятность и не процент «красоты». Это игровое число `1…100`.
- Модель аппроксимирует рубрику, поэтому возможны отклонения до ~3 баллов
  и редкие локальные падения до 0.5 балла.
